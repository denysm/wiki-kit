# Швидкий старт: власна вікі знань приблизно за 30 хвилин

[English version](QUICKSTART.md) · [Русская версия](QUICKSTART.ru.md)

Ви отримаєте особисту вікі на своєму комп'ютері. Ви даєте їй чати, нотатки, документи й посилання; ШІ-асистент (Claude) перетворює їх на короткі статті, де кожне твердження має джерело, і відповідає на ваші запитання за ними. Поверх працює набір «спеціалістів»: коуч, допомога з рішеннями, документами, підготовкою до лікаря та інше. Ваші дані залишаються на вашому комп'ютері.

## Що потрібно

- Комп'ютер з macOS, Linux або Windows 10/11 (на Windows замість кроків 2-5 — [розділ Windows](#windows-10-або-11)).
- Інтернет.
- Платна підписка Claude (Pro або вища) або API-ключ Anthropic. Встановлення безкоштовне, робота ШІ — платна.
- Акаунт GitHub (безкоштовно) — бажано. Для встановлення й роботи він не потрібен, але через нього ви надсилаєте свої покращення: [Як поділитися покращеннями](#як-поділитися-покращеннями).

## Крок 1. Встановіть VS Code

VS Code — безкоштовний редактор: у ньому ви читатимете свою вікі й розмовлятимете з Claude.

1. Відкрийте <https://code.visualstudio.com>, завантажте, встановіть, запустіть.
2. На лівій панелі квадратний значок **Extensions** (або `Cmd+Shift+X` на Mac, `Ctrl+Shift+X` на Linux). Знайдіть **Claude Code** від **Anthropic**, натисніть **Install**.

## Крок 2. Відкрийте Термінал

Термінал — вікно, куди вставляють команди. Вставили команду, натиснули Enter, дочекалися, поки знову з'явиться курсор.

- Mac: `Cmd+Пробіл`, наберіть `Terminal` (або «Термінал»), Enter.
- Linux: `Ctrl+Alt+T`.

Якщо Mac запропонує встановити «інструменти розробника командного рядка», натисніть **Встановити** й зачекайте — це нормально.

## Крок 3. Встановіть Claude Code і увійдіть

```sh
curl -fsSL https://claude.ai/install.sh | bash
```

Потім наберіть `claude` і натисніть Enter. Відкриється браузер для входу в акаунт Claude (або він попросить API-ключ). Після входу наберіть `/exit`, щоб вийти.

## Крок 4. Завантажте кит

```sh
git clone ADDRESS ~/Projects/wiki-kit
```

Замість `ADDRESS` вставте адресу кита: на його сторінці в GitHub натисніть зелену кнопку **Code** і скопіюйте адресу HTTPS (вона закінчується на `.git`). Кит відкритий: щоб його завантажити, акаунт GitHub не потрібен.

## Крок 5. Запустіть інсталятор

```sh
bash ~/Projects/wiki-kit/bootstrap.sh --lang uk
```

Він ставить плагін вікі, створює вашу вікі в папці `~/wiki`, додає спеціалістів і перевіряє сам себе. Останні рядки показують підсумок:

```
Done: 15 ok, 0 note(s), 0 failure(s). Hub: /Users/you/wiki
```

`0 failure(s)` — усе готово. Кожен рядок `FAIL` або `note` каже, що зробити; зробіть і запустіть ту саму команду ще раз (повторний запуск безпечний). `--lang uk` — правила вікі й спілкування українською; `--hub ~/Documents/wiki` — інша папка.

## Windows 10 або 11

Крок 1 той самий. Замість кроків 2-5:

1. **Відкрийте PowerShell**: меню «Пуск», наберіть `PowerShell`, Enter (звичайне вікно, не «від імені адміністратора»).
2. **Встановіть Git**, потім закрийте PowerShell і відкрийте знову:

   ```powershell
   winget install --id Git.Git -e
   ```
   Якщо `winget` не знайдено, завантажте Git з <https://git-scm.com/download/win> і встановіть, погоджуючись з усіма варіантами за замовчуванням.
3. **Завантажте кит.** `ADDRESS` замініть, як у кроці 4.

   ```powershell
   git clone ADDRESS $HOME\Projects\wiki-kit
   ```
4. **Запустіть інсталятор** (Windows за замовчуванням забороняє завантажені скрипти; ця команда дозволяє один запуск):

   ```powershell
   powershell -ExecutionPolicy Bypass -File $HOME\Projects\wiki-kit\bootstrap.ps1 -Lang uk
   ```
   Перед встановленням Python і Claude Code він спитає дозволу: натисніть Enter, щоб погодитися. Якщо наприкінці є рядок `note` про Claude Code, закрийте PowerShell, відкрийте знову й запустіть ту саму команду ще раз.
5. **Увійдіть у Claude**: наберіть `claude`, увійдіть у браузері, потім `/exit`.

Далі — крок 6. Ваша вікі — папка `wiki` у папці користувача (`C:\Users\<ім'я>\wiki`); де в тексті `Cmd`, натискайте `Ctrl`.

Інсталятор для Windows новий: якщо в якомусь рядку `FAIL`, надішліть тому, хто надіслав вам кит, файл журналу з останнього рядка інсталятора (`%TEMP%\wiki-kit-bootstrap.log`). Конвертери PDF і Word у киті використовують інструменти macOS і на Windows поки не працюють.

## Крок 6. Почніть роботу

1. У VS Code: **File → Open Folder…** (Файл → Відкрити папку), виберіть папку `wiki` у домашній папці.
2. Відкрийте Claude: значок Claude у правому верхньому куті редактора або `Cmd+Esc` / `Ctrl+Esc`.
3. Створіть першу тему (тема — одна сфера життя: особисте, кар'єра, здоров'я, хобі):

   ```
   /wiki init personal
   ```
4. Дайте їй щось прочитати — посилання, файл або просто текст:

   ```
   /wiki:ingest https://example.com/stattia-yaka-spodobalas
   /wiki:ingest ~/Downloads/notatky.pdf
   ```
5. Перетворіть джерела на статті й ставте запитання:

   ```
   /wiki:compile
   /wiki:query що я вирішив щодо переїзду?
   ```
6. Спеціалісти. Попросіть Claude звичайними словами: «увімкни спеціалістів для теми personal». Після цього фрази «коуч», «допоможи вибрати», «підготуй до лікаря», «перевір факти» самі знаходять потрібного спеціаліста в будь-якій папці. Під час першої розмови він спитає, якою мовою вам зручніше.

Завжди можна просто написати, що ви хочете, звичайними словами: Claude сам вибере команду.

## Корисні звички

- **Одне завдання — одна розмова.** Довгі розмови дорожчі. Закінчили завдання — почніть нову розмову (кнопка `+` на панелі Claude).
- **Оновлення** раз на тиждень: `cd ~/Projects/wiki-kit && git pull`. Спеціалісти у вашій вікі оновляться самі.
- **Секретам** (паролі, ключі, банківські реквізити) у вікі не місце. Claude замінює їх на `[REDACTED:secret]`, коли помічає.
- **У киті немає даних.** Ваша вікі окремо від кита, і її копії в інтернеті немає.
- **Чорнові спеціалісти.** Усі спеціалісти, крім коуча, — чернетки (версія 0.x) і самі про це кажуть. Спеціалісти зі здоров'я, грошей, документів та емоційної підтримки допомагають підготуватися, але не замінюють лікаря, консультанта, юриста чи психотерапевта.

## Як поділитися покращеннями

Кит росте з досвіду тих, хто ним користується: незрозумілий крок, скрипт з помилкою, фраза, яку спеціаліст не зрозумів, урок, який йому варто засвоїти. Свої зміни ви надсилаєте як *pull request* — пропозицію, яку автор кита переглядає й додає до кита. Іде лише сама зміна; ваша вікі залишається на вашому комп'ютері.

**Один раз:**

1. Зареєструйтеся безкоштовно на <https://github.com/signup>. Потім відкрийте <https://github.com/settings/emails>, увімкніть **Keep my email addresses private** і скопіюйте з цієї сторінки адресу, що закінчується на `@users.noreply.github.com`.
2. Встановіть програму GitHub для командного рядка з <https://cli.github.com> (Windows: `winget install --id GitHub.cli -e`; Mac з Homebrew: `brew install gh`) і увійдіть: `gh auth login`, потім виберіть GitHub.com, HTTPS і «Login with a web browser».
3. Скажіть git, хто ви, лише для папки кита (адреса з пункту 1 приховує справжню пошту; замість імені можна нік):

   ```sh
   cd ~/Projects/wiki-kit
   git config user.name "Ваше Ім'я"
   git config user.email "ID+USERNAME@users.noreply.github.com"
   ```
4. Впишіть у `~/.config/wiki-kit/private-names.txt` імена, які ніколи не повинні залишити комп'ютер (родина, роботодавець, клієнти), по одному на рядок. Інсталятор увімкнув перевірку: вона не надішле нічого, що збігається з ними або схоже на пароль чи ключ.

**Кожна зміна:**

1. У VS Code відкрийте папку `~/Projects/wiki-kit` і скажіть Claude, що має працювати інакше.
2. Коли результат подобається, попросіть Claude: «надішли мої зміни в кит як pull request». Він зробить вашу копію кита на GitHub (*fork*), покладе зміну в окрему гілку й відкриє pull request. Вручну:

   ```sh
   cd ~/Projects/wiki-kit
   gh repo fork --remote            # один раз: ваша копія на GitHub; оригінал кита стане "upstream"
   git switch -c korotka-nazva
   git add -A
   git commit -m "Що змінилося і навіщо"
   git push -u origin HEAD          # тут спрацьовує перевірка на витоки
   gh pr create --fill              # якщо спитає, куди надіслати, виберіть оригінальний кит, а не свою копію
   ```
3. Автор кита може поставити запитання просто в pull request, потім прийме його. Після цього поверніться до основної версії й оновіться: `git switch main`, потім `git pull`.

Писати можна будь-якою мовою: українською, російською, англійською. Для уроків спеціалістам свої правила (без особистих деталей, плюс приклад-перевірка): [specialists/README.md](../specialists/README.md#from-personal-lesson-to-shared-principle). Усе інше — у [CONTRIBUTING.md](../CONTRIBUTING.md) (англійською).

## Якщо щось не так

| Що бачите | Що робити |
|---|---|
| `git is missing` або `python3 is missing` | Mac: виконайте `xcode-select --install`, дочекайтеся, запустіть інсталятор знову. Linux: встановіть пакети `git` і `python3`. |
| `Claude Code command line not found` | Зробіть крок 3, закрийте й знову відкрийте Термінал, запустіть інсталятор знову. |
| `git clone` просить пароль або пише «not found» | В адресі помилка: скопіюйте її знову із зеленої кнопки **Code** (крок 4). |
| `plugin install failed` | Виконайте `claude plugin install wiki@llm-wiki` і прочитайте повідомлення. Зазвичай справа в інтернеті. |
| VS Code не знає команду `/wiki` | Повністю закрийте VS Code і відкрийте знову. |
| Windows: «виконання сценаріїв вимкнено в цій системі» | Запускайте інсталятор повною командою з розділу Windows (`powershell -ExecutionPolicy Bypass -File ...`). |
| Windows: `winget` не знайдено | Встановіть Git з <https://git-scm.com/download/win> і Python з <https://www.python.org/downloads/> (позначте **Add python.exe to PATH**), потім знову запустіть інсталятор. |
| Щось інше | Скопіюйте рядки з `FAIL` і надішліть тому, хто надіслав вам кит. |
