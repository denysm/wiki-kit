# Быстрый старт: своя вики знаний примерно за 30 минут

[English version](QUICKSTART.md)

Вы получите личную вики на своём компьютере. Вы даёте ей чаты, заметки, документы и ссылки; ИИ-ассистент (Claude) превращает их в короткие статьи, где у каждого утверждения есть источник, и отвечает на ваши вопросы по ним. Поверх работает набор «специалистов»: коуч, помощь с решениями, документами, подготовкой к врачу и другое. Ваши данные остаются на вашем компьютере.

## Что нужно

- Компьютер с macOS, Linux или Windows 10/11 (на Windows вместо шагов 2-5 — [раздел Windows](#windows-10-или-11)).
- Интернет.
- Платная подписка Claude (Pro или выше) или API-ключ Anthropic. Установка бесплатна, работа ИИ — платная.

## Шаг 1. Установите VS Code

VS Code — бесплатный редактор: в нём вы будете читать свою вики и разговаривать с Claude.

1. Откройте <https://code.visualstudio.com>, скачайте, установите, запустите.
2. На левой панели квадратный значок **Extensions** (или `Cmd+Shift+X` на Mac, `Ctrl+Shift+X` на Linux). Найдите **Claude Code** от **Anthropic**, нажмите **Install**.

## Шаг 2. Откройте Терминал

Терминал — окно, куда вставляют команды. Вставили команду, нажали Enter, дождались, пока снова появится курсор.

- Mac: `Cmd+Пробел`, наберите `Terminal` (или «Терминал»), Enter.
- Linux: `Ctrl+Alt+T`.

Если Mac предложит установить «инструменты разработчика командной строки», нажмите **Установить** и подождите — это нормально.

## Шаг 3. Установите Claude Code и войдите

```sh
curl -fsSL https://claude.ai/install.sh | bash
```

Затем наберите `claude` и нажмите Enter. Откроется браузер для входа в аккаунт Claude (или он попросит API-ключ). После входа наберите `/exit`, чтобы выйти.

## Шаг 4. Скачайте кит

```sh
git clone ADDRESS ~/Projects/wiki-kit
```

Вместо `ADDRESS` вставьте адрес кита: на его странице в GitHub нажмите зелёную кнопку **Code** и скопируйте адрес HTTPS (он кончается на `.git`). Кит открытый: чтобы его скачать, аккаунт GitHub не нужен.

## Шаг 5. Запустите установщик

```sh
bash ~/Projects/wiki-kit/bootstrap.sh --lang ru
```

Он ставит плагин вики, создаёт вашу вики в папке `~/wiki`, добавляет специалистов и проверяет сам себя. Последние строки показывают итог:

```
Done: 15 ok, 0 note(s), 0 failure(s). Hub: /Users/you/wiki
```

`0 failure(s)` — всё готово. Каждая строка `FAIL` или `note` говорит, что сделать; сделайте и запустите ту же команду ещё раз (повторный запуск безопасен). `--lang ru` — правила вики и общение на русском; `--hub ~/Documents/wiki` — другая папка.

## Windows 10 или 11

Шаг 1 тот же. Вместо шагов 2-5:

1. **Откройте PowerShell**: меню «Пуск», наберите `PowerShell`, Enter (обычное окно, не «от имени администратора»).
2. **Установите Git**, затем закройте PowerShell и откройте снова:

   ```powershell
   winget install --id Git.Git -e
   ```
   Если `winget` не найден, скачайте Git с <https://git-scm.com/download/win> и установите, соглашаясь со всеми вариантами по умолчанию.
3. **Скачайте кит.** `ADDRESS` замените, как в шаге 4.

   ```powershell
   git clone ADDRESS $HOME\Projects\wiki-kit
   ```
4. **Запустите установщик** (Windows по умолчанию запрещает скачанные скрипты; эта команда разрешает один запуск):

   ```powershell
   powershell -ExecutionPolicy Bypass -File $HOME\Projects\wiki-kit\bootstrap.ps1 -Lang ru
   ```
   Перед установкой Python и Claude Code он спросит разрешения: нажмите Enter, чтобы согласиться. Если в конце есть строка `note` про Claude Code, закройте PowerShell, откройте снова и запустите ту же команду ещё раз.
5. **Войдите в Claude**: наберите `claude`, войдите в браузере, затем `/exit`.

Дальше — шаг 6. Ваша вики — папка `wiki` в папке пользователя (`C:\Users\<имя>\wiki`); где в тексте `Cmd`, нажимайте `Ctrl`.

Установщик для Windows новый: если в какой-то строке `FAIL`, отправьте тому, кто прислал вам кит, файл журнала из последней строки установщика (`%TEMP%\wiki-kit-bootstrap.log`). Конвертеры PDF и Word в ките используют инструменты macOS и на Windows пока не работают.

## Шаг 6. Начните работу

1. В VS Code: **File → Open Folder…** (Файл → Открыть папку), выберите папку `wiki` в домашней папке.
2. Откройте Claude: значок Claude в правом верхнем углу редактора или `Cmd+Esc` / `Ctrl+Esc`.
3. Создайте первую тему (тема — одна область жизни: личное, карьера, здоровье, хобби):

   ```
   /wiki init personal
   ```
4. Дайте ей что-нибудь прочитать — ссылку, файл или просто текст:

   ```
   /wiki:ingest https://example.com/statya-kotoraya-ponravilas
   /wiki:ingest ~/Downloads/zametki.pdf
   ```
5. Превратите источники в статьи и задавайте вопросы:

   ```
   /wiki:compile
   /wiki:query что я решил про переезд?
   ```
6. Специалисты. Попросите Claude обычными словами: «включи специалистов для темы personal». После этого фразы «коуч», «помоги выбрать», «подготовь к врачу», «проверь факты» сами находят нужного специалиста в любой папке. При первом разговоре он спросит, на каком языке вам удобнее.

Всегда можно просто написать, что вы хотите, обычными словами: Claude сам выберет команду.

## Полезные привычки

- **Одна задача — один разговор.** Длинные разговоры дороже. Закончили задачу — начните новый разговор (кнопка `+` в панели Claude).
- **Обновления** раз в неделю: `cd ~/Projects/wiki-kit && git pull`. Специалисты в вашей вики обновятся сами.
- **Секретам** (пароли, ключи, банковские реквизиты) в вики не место. Claude заменяет их на `[REDACTED:secret]`, когда замечает.
- **В ките нет данных.** Ваша вики отдельно от кита, и её копии в интернете нет. Чтобы предлагать улучшения для кита, нужен аккаунт GitHub (вход: `gh auth login`, <https://cli.github.com>); установщик уже включил проверку, которая не отправит ничего похожего на ваши данные. Перед первым предложением впишите в `~/.config/wiki-kit/private-names.txt` имена, которые никогда не должны покинуть компьютер (семья, работодатель, клиенты), по одному на строку.
- **Черновые специалисты.** Все специалисты, кроме коуча, — черновики (версия 0.x) и сами об этом говорят. Специалисты по здоровью, деньгам, документам и эмоциональной поддержке помогают подготовиться, но не заменяют врача, консультанта, юриста или психотерапевта.

## Если что-то не так

| Что видите | Что делать |
|---|---|
| `git is missing` или `python3 is missing` | Mac: выполните `xcode-select --install`, дождитесь, запустите установщик снова. Linux: установите пакеты `git` и `python3`. |
| `Claude Code command line not found` | Сделайте шаг 3, закройте и снова откройте Терминал, запустите установщик снова. |
| `git clone` просит пароль или пишет «not found» | В адресе опечатка: скопируйте его снова с зелёной кнопки **Code** (шаг 4). |
| `plugin install failed` | Выполните `claude plugin install wiki@llm-wiki` и прочитайте сообщение. Обычно дело в интернете. |
| VS Code не знает команду `/wiki` | Полностью закройте VS Code и откройте снова. |
| Windows: «выполнение сценариев отключено в этой системе» | Запускайте установщик полной командой из раздела Windows (`powershell -ExecutionPolicy Bypass -File ...`). |
| Windows: `winget` не найден | Установите Git с <https://git-scm.com/download/win> и Python с <https://www.python.org/downloads/> (отметьте **Add python.exe to PATH**), затем снова запустите установщик. |
| Что-то другое | Скопируйте строки с `FAIL` и отправьте тому, кто прислал вам кит. |
